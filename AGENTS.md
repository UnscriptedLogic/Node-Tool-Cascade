# Project conventions

- Keep documentation short, simple, and focused on users.
- Do not list AI tools or assistants as authors, contributors, or co-authors.
- Do not add AI attribution, generation notices, or development-assistance remarks to project files, commit messages, or pull requests.
- Provider names and integration documentation may describe app functionality.
- Preserve required license and third-party copyright notices.

## Commits and versions

- Use ✨ for features, 🐞 for bug fixes, and 🛠️ for refactors and all other changes.
- Start commit titles with the matching emoji, followed by exactly three words.
- Use semantic versioning: major for breaking changes, minor for compatible features, patch for fixes and maintenance.
